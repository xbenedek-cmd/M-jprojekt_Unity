# Progeny of the Ashes (Unity)

Iba zdrojový kód projektu (C# skripty, editorové nástroje, shadery, manifest balíkov). Modely, textúry, zvuky, scény, prefaby a assety tretích strán (NatureManufacture, Grass Pack) v repozitári nie sú.
Editorové menu `Progeny` generuje svet, cesty a navigáciu zo skriptov v `Assets/Editor`.
